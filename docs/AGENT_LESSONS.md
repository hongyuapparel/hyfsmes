## 后续如何维护

- 新错误先核对事实和现有条款；同类案例补在对应项，不为每个订单、按钮新建规则文件。
- 规则写成触发场景和可检查结果，不写“保证没有 bug”等无法验证的承诺。
- 执行规则只维护在上述规范正文，根目录 `AGENTS.md` 保持入口职责。通过主分支版本管理传递，不依赖单个对话或个人记忆。
