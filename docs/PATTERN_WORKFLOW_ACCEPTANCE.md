# 纸样工作流程验收（2026-09-09）

本次验证的是本工作树预览站 `127.0.0.1:5187`、后端 `3107` 和本机测试数据库。未部署生产。测试用四张临时订单和临时权限账号已删除，不修改正式订单。

## 已落实的操作方式

- 单张订单从“查看”进入工作区；选中两张及以上，列表才出现分配师傅、确认完成。
- 区块操作放在右上角，复用现有按钮和区块。编辑用料时只提供取消、保存用料，保存后再确认完成。
- 订单已有物料名称、幅宽等自动带入。允许先保存草稿，但必须保存有效物料名称和正数单件用量才能完成；图片、备注等仍选填。
- 已完成订单可修正用量，保留原完成时间和状态，记录修改人、时间及前后内容。

## 验证结果

| 场景 | 方式及结果 |
|---|---|
| 单选与多选、统一按钮叫法 | 浏览器实际勾选、打开详情，符合约定 |
| 未选师傅直接分配 | 浏览器提示两个必填项，正确分配后详情和记录更新 |
| 自动带入已有资料 | 浏览器确认名称、幅宽带入，不要求重新填写 |
| 填到一半关闭、取消修改 | 浏览器出现放弃确认；继续编辑保留输入，放弃后数据库保留原资料 |
| 草稿、空用量、空白新增行 | 浏览器允许存草稿；缺用量完成被拦截；多余全空行不影响有效用料保存 |
| 单张完成、不上传图片 | 浏览器完成成功，数据库状态和记录一致 |
| 多单中有流程缺项 | 浏览器列出具体订单问题，所有订单均未提前完成 |
| 两张合格订单完成 | 浏览器成功，逐单回读状态、完成时间、完成记录和流转历史一致 |
| 完成后修正与查记录 | 浏览器将 1.1 改为 1.35，记录显示前后值和说明，完成时间不变 |
| 两人同时保存 | 本机真实接口并发，同版本一份成功、一份冲突；前端测试确认冲突保留输入 |
| 只有纸样页面权限 | 本机临时角色可查纸样资料/纸样记录，无权调用订单记录及未授权修改接口 |
| 保存记录失败 | 后端回归测试验证用料、分配、完成、图片修改会撤回相应业务修改 |
| 日期边界、天数排序、筛选统计与导出 | 后端回归测试通过，包括当天、跨日、跨月、跨年、空日期等 |
| 中途请求失败、重试、加载失败 | 前端回归测试通过；已成功订单不重复提交，记录加载失败明确显示 |
| 视觉检查 | 浏览器在默认 1920×855 与 1366×768 视口查看填写和只读状态，区块按钮与输入未遮挡；检查后恢复默认视口 |

自动化回归共 58 项通过（后端 35、前端 23）。前后端构建通过，前端构建包含现有 UI 规范检查。

## 尚未完成的跨部门验收

纸样实测用量保存在纸样资料中，采购、工艺、裁床目前读取订单的大货用料。两者不是自动同步的同一份资料。本次未擅自覆盖大货用料。

待确认：实测用量是供其他部门参考，还是直接作为大货用量依据？建议先以“纸样实测用量”单独展示参考，保留大货用料。确认后还需实施对应资料入口及跨部门权限、更新回读测试。

本机现有纸样完成规则只覆盖部分订单类型与裁片合作方式，并流转到订单完成；未匹配规则的测试订单已正确拦截。未验证生产站所有配置组合，不能据此宣称所有生产环节已全面打通。

模拟操作覆盖常见工作与异常，但不能替代纸样师傅真实工作试用；真实网络中断等尚未做浏览器故障注入。多单统一预检能拦截已知缺项，但后续逐单提交遇到临时错误时仍可能部分成功，界面保留未成功订单供重试。
