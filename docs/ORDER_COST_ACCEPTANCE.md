## 已实施的整改

1. 订单详情、成本快照、公共选项同时请求；核心数据返回即展示成本，不等待工序/物料选项。选项未就绪时禁止编辑和提交，失败有专门的重试入口。
2. 核心请求短暂失败时，只对失败请求并行重试一次；持续失败显示失败页，不展示可保存的空表。复用已有标签身份隔离和公共选项请求缓存，避免后台标签跟着当前路由重复查询。
3. 成本页显示订单主图与去重后的图片预览，增加单件成本、销售价毛利、目标毛利率、建议出厂价及固定底部操作栏。
4. 只按持久化字段判断未保存修改；搜索、勾选不误报，离开前可继续编辑或放弃，提交中禁止重复提交与导航。
5. 按用户确认的规则：订单内容与成本不同时只提醒，明确确认后才同步；保留匹配单价，同名多变体无法可靠匹配时不擅自套用价格。
6. 缺失成本项目在确认报价前提醒；保存草稿不改变已确认出厂价。
7. 修正历史代码将 15% 毛利率改成 10% 的逻辑，成本 GET 不再写数据库。加载工序目录不再自动计入第一条工序，也不再覆盖已保存工序单价。
